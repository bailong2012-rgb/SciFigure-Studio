SciFigure Studio 0.1

下载解压后双击 index.html，即可使用。无需账号、网络或安装运行环境。

画图

点击或框选元素，Shift 多选。拖动四角缩放；拖动选框上方的圆形手柄旋转，Shift 按 15° 吸附。双击文字修改。右侧可精确设置位置、尺寸、颜色。

快捷键

Ctrl+Z 撤销 · Ctrl+Shift+Z 重做
Ctrl+D 复制 · Ctrl+C/V 内部复制粘贴
Ctrl+A 全选 · Delete 删除
方向键微调，Shift 移动 10 单位
空格拖动平移 · Ctrl+滚轮缩放

项目与素材

项目库支持新建、重命名、复制和删除。项目自动保存在当前浏览器，换电脑或移动便携文件夹前，请备份工程和素材包。

导入 SVG 才能编辑矢量内容；PNG 不是可拆分的矢量图。SVG 文件中的脚本和外部资源不受支持。素材库按页读取，适合逐步扩充。

开源与扩展

软件代码 MIT；随附原创示例素材 CC0。导入素材保留自己的许可。详细格式和扩展入口见 docs 文件夹。
