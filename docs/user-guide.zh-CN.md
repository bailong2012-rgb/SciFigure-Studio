# SciFigure Studio 0.1.0

免费开源的科研矢量绘图工具，离线便携版。基于 SVG、原生 JavaScript 和 IndexedDB，无运行时依赖、账号、服务器或遥测。

## 使用

下载并完整解压 `SciFigure-Studio-0.1.0-portable.zip`，双击 `启动 SciFigure.cmd`，或者用 Edge / Chrome 打开 `index.html`。不要直接在压缩包内打开，也不要单独移动 HTML 而遗漏旁边的 JS/CSS。

第一启动会载入 A/B/C 示例科研图和 18 类原创素材。点击“＋ 新建”开始空白画布；右侧可设置画布尺寸。项目库可以打开、重命名、复制和删除项目。

选中元素后，**四角方块缩放，选框上方中央的圆形手柄旋转**。按住 Shift 拖动旋转手柄按 15° 对齐；右侧数值可精确调节。双击文字编辑。拖动空白区域框选，Shift 多选，组合/拆组后继续编辑。

## 0.1 已提供

- 多项目和本机自动保存；工程备份、导入和原编辑器工程迁移。
- SVG 单个/批量导入；素材名称、分类、标签、作者、来源、许可编辑；搜索与收藏。
- `.sciassets` 素材包导入、导出；发生编号冲突时分配新编号，避免覆盖已有素材。
- 18 类原创素材及可编辑示例图。素材库每页最多 48 张缩略图，矢量内容按需读取。
- 四角缩放、顶部旋转手柄、精准属性、框选、多选、组合、拆组、复制、删除、图层顺序、隐藏与锁定。
- 对齐、水平/垂直等距分布、网格和对象参考线吸附、缩放和平移。
- SVG 和 1×/2×/3× PNG 导出；SVG 保留路径与文字。
- 版本化工程与素材格式，模块边界、事件和导入/导出器扩展入口。

## 便携文件与本机存储

软件文件可以移动，**浏览器自动保存的数据不会自动跟着文件夹移动**。更换电脑、浏览器、目录，或清理浏览器数据前，请用“备份工程”和“导出素材包”保存文件。到新电脑后重新导入即可。

IndexedDB 不可用时会明确提示临时存储；临时状态关闭即丢失。无任何内容会上传网络。`file://` 的浏览器存储隔离规则可能不同，0.1 的目标平台为 Windows Edge/Chrome。

## 素材库的长期扩展

用“导入 SVG”加入一个或多个矢量文件，再点素材卡片上的“编辑”填写名称、分类和标签。建议使用中英文关键词。按领域组织素材包，例如细胞膜、细胞器、免疫细胞、组织结构、实验仪器。

本版测试了 10,000 条合成素材元数据的分页，**并未附带或测试一万个高复杂度真实插画**。真实容量和速度取决于素材复杂度、浏览器存储配额和设备。适合先建立规范化素材库，后续按真实素材批次测量。

单个 SVG ≤8 MB、≤50,000 个 SVG 节点；批量 SVG ≤1,000 个文件；单素材包 ≤128 MB、≤10,000 条；工程 SVG 内容 ≤30 MB；画布边长 64–12,000；PNG 总像素 ≤50,000,000。超过限制会提示，不会静默截断。

支持普通 SVG 路径、文字、渐变、裁剪、蒙版、内部引用及部分滤镜/样式。禁止脚本、动画、外链资源等主动内容；高级 CSS 选择器可能被拒绝并提示。嵌入的 PNG/JPEG/WebP 可以显示，但其内部像素不能拆成矢量路径。SVG 文字仍依赖本机字体。

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |
| 复制副本 | Ctrl+D |
| 软件内部复制 / 粘贴 | Ctrl+C / Ctrl+V |
| 全选 / 取消选择 | Ctrl+A / Esc |
| 删除 | Delete |
| 微调 | 方向键；Shift 为 10 单位 |
| 平移 / 缩放 | 空格拖动 / Ctrl+滚轮 |
| 暂时关闭移动吸附 | Alt 拖动 |
| 备份工程 | Ctrl+S |

## 开发和扩展

打开 `src/index.html` 即可开发；修改源文件后刷新。构建：`python build.py`，只用 Python 标准库，不需要 npm。使用者不需要 Python。

详见 `docs/architecture.md`、`docs/formats.md`、`docs/verification.md`。代码 MIT，原创建模图标 CC0；导入素材保持自己的授权说明。公开发布前可修改产品名、署名和许可策略，但不能把导入素材自动视为代码许可覆盖的内容。
