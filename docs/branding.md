# 品牌标识 · 2026-10-05

母品牌：刚刚BME，位于应用顶部几何居中。原始透明 logo 来自用户已有的视频项目：`剪辑/outputs/sonic-gate-bme/刚刚BME-透明logo.png`，复制到 `src/ganggang-bme-logo.png`，原图像素未改动。

旁边的小型横排字标使用：刚刚 #EE9CAB，B #83C7E3，M #F3C778，E #CEA2BD，配合深色界面。文字大小 19/22 px，原标识显示 36 × 36 px。

子软件：SciFigure Studio，左上角配原创 SVG 细胞标识 `src/scifigure-cell.svg`。青色半开放膜轮廓、红色小细胞核、一个矢量路径节点，64 × 64 viewBox；界面显示 44 × 44 px，同时用作页签图标。此标识为本软件界面绘制的可缩放矢量，不依赖位图生成。

项目名称和保存状态移至画布上方，保留原有控件 ID 和功能。母品牌始终独立于子软件名称，便于后续同一品牌下增加不同工具。

用户品牌图片及字标不属于基础科研素材 CC0 包，MIT 代码许可不自动授予品牌使用权。
